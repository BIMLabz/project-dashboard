Paper: https://arxiv.org/abs/2609.24974

Your fancy harness just blocked a risky bash move. That rule lives in the harness (the small runtime around the model: tools, prompts, guardrails, control code), so if you ship without it, the block is gone.

Harness-Zero (Ye et al.) asks whether you can train the model so those habits stick after you yank the fancy harness off.

They start with a thin harness: a mini coding loop with one Bash tool. They evolve a fatter harness on top (extra tools, guardrails, skills). During training, a second agent reads those fat-harness rules and either passes the student's next reply or replaces it with a small fix, still written as a bash reply the thin harness can run. Then they train the student a bit more on those accepted turns so it copies the habit, and at ship time they throw away the fat harness, the review agent, and the private rulebook.

Same Qwen3.5-9B. Same thin bash harness at test time. Share of tasks finished correctly (averaged across spreadsheet work, multi-app tool use, and a science task set):

23.3% base → 44.3% after Harness-Zero with the fat harness gone, ahead of 41.7% when the fat harness stays attached

The trained student under plain bash beats the base model that still has the specialized harness mounted. After training, the thin loop alone carries the habit. You can drop the coach when you ship.
