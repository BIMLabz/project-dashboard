Self-Healing Harness daily draft (2026-09-23)

Status: CEO PASS with patches applied. Show Ashish for cut. Do not post. Owner publishes.

Paper: https://arxiv.org/abs/2609.24130 Authors: Tayebati, Kumar, Darabi, Krishnan, Trivedi

Self-score (draft gate 1–10): PASS (CEO verified)

Your agent just wrote itself a new standing rule after a failure. The rule fixes that failure. It also breaks a case that used to pass.

If you keep every self-authored fix that "helps," you ship the regression.

Tayebati et al. wrap an unmodified agent in a self-healing harness: a small runtime around the model that watches the run, lets the agent draft a candidate rule, and keeps that rule provisional until an external gate says yes. Weights stay fixed. The agent proposes. The gate decides what persists.

Promotion needs two things: the rule must improve the failure that triggered it, and it must not drop previously good cases past a fixed margin when those cases are replayed. A weaker forward trial is used only when replay is unavailable.

Across 16 matched Baseline vs Harness runs on AppWorld, Terminal-Bench, and τ²-bench (four models), the gate made 383 replay-decided rejections. Of those:

211 of 383 (55%) improved the triggering failure while degrading a protected case that previously succeeded

A keep rule keyed only to "did it fix the bug that triggered it" would have admitted all 211. Local win is not enough when the same edit quietly breaks something that already worked.
