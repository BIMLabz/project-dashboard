Post (copy into X)

You ship a coding agent (a loop that asks a model for the next token until it stops).

Someone asks for a bugfix. The model keeps writing until end-of-text. No tool. No Allow button. No second look at the repo. Whatever landed after the prompt is the answer.

That is the V0 harness. A while-not-EOS sampling loop. Top-p. An environment that scores the string. No skills. No memory. No world interrupt.

GPT-2 (Radford 2019) showed how far that bare loop could go on zero-shot transfer. On CoQA reading comprehension, answers hit 55 F1 without the 127,000+ training examples the baselines used.

If your product still finishes because the model stopped talking, not because the world confirmed anything, you are still on V0. Everything later on this list is one new thing the loop is allowed to do.
