The long job crashes mid-tool. You restart. The last user line is gone. The interrupted tool call is gone. The agent apologizes and asks what you wanted.

That is not memory. That is amnesia with vibes.

MemGPT (Packer 2023) treats the model like a CPU: main memory plus disk, and pages via function calls. Working context and a FIFO queue sit in the hot window. Recall and archival stores sit outside. Under pressure, dump what matters out of the FIFO. When full, evict and summarize. The rest stays on disk.

On a multi-session retrieval task in the paper: 32.1% -> 92.5%.

Durable receipts beat "everything still in the prompt." If restart rewrites the last user line or drops the interrupted tool, you do not have managed state.
