Your coding agent (the loop that gives a model tools and lets it edit a repo) needs five minus three.

It keeps talking and invents "2." Or worse, it invents a whole API reply. No one stopped the decode to run the calculator.

Toolformer (Schick 2023) is the interrupt pattern. The model emits a call. Decoding stops at the arrow. The harness (everything between weights and the world) runs the API, pastes the result back, then decoding continues. The model never gets to invent the tool answer.

Same GPT-J 6.7B guest. Math with the calculator path on: 40.4 on ASDiv. Plain GPT-J without tools: 7.5.

That gap is not smarter weights. It is interrupt, execute, insert observation, resume. If your Allow button does not actually pause the model until the tool finished, Allow is cosplay.
