You pick a coding agent from a chart that only names the model. This paper says that chart is mostly ranking the wrapper: the coding shell that runs tools, applies the patch, and grades whether the bug is fixed.

Same mid-size open model (Qwen3-8B). Same frozen practice runs from four production shells. Change only which shell grades the model after that training run, and the share of sealed real GitHub bug-fix tasks it fixes (SWE-bench Verified) jumps by a factor of 4.3 (2.14% under Aider, 9.27% under OpenHands across 24,000 sealed evals).

Change the training recipe on that same model and the mean only moves from 5.55% to 6.46% (factor 1.16).

Next time a leaderboard only lists the weights, ask which shell ran the eval.
